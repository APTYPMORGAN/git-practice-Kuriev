Проблема 1: Ошибка "bash: cd: C:Users... No such file or directory"
Причина: Попытка использовать обратные слэши "\" Windows в терминале Git Bash.
Решение: Использовать прямые слэши "/" и формат диска Unix.
Пример: cd /c/Users/Student_01/Documents/Lab2_ISRPO_Kuriev

Проблема 2: Ошибка "error: src refspec main does not match any" при git push.
Причина: Локально отсутствовала ветка с именем "main" (из-за старых настроек
Git локальная ветка создалась с именем "master", либо еще не было
сделано ни одного коммита).
Решение: Сделать первый коммит (git commit) и принудительно переименовать
текущую ветку в main перед отправкой:
git branch -M main
git push -u origin main
